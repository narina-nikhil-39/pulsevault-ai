# Archify — Architecture Diagram & System Visualizer Skill

Archify is an agent skill that compiles codebase architecture, component relationships, and data workflows into standalone interactive HTML diagrams and flowcharts.

## Capabilities

1. **System Flowcharts & Architecture Maps**: Generate interactive diagrams showing clients, web gateways, backend microservices, database storage, and external API integrations.
2. **Pipeline Visualizers**: Render multi-stage processing pipelines (such as clinical OCR, entity extraction, normalization, and safety audit stages) as visual flowcharts.
3. **Sequence & Data Flow Maps**: Diagram request/response cycles, token authentication, and data persistence workflows.

## Output Format

- Produces clean HTML/SVG interactive diagrams with dark mode styling, node filtering, and zoom/pan capabilities.
- Renders responsive flowcharts embedded with Mermaid.js or standalone HTML visualizers.
